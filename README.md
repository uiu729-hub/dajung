# 다정 알림장

> 크게, 쉽게, 따뜻하게

초등 1학년 손주의 알림장과 가정통신문을 쉽게 읽도록 돕는 브랜드 소개 페이지입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 한 장짜리 소개 페이지 (이미지 없음, 모바일 대응) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 보여 주도록 하는 빈 파일 |
| `README.md` | 이 설명 파일 |

## 올리기 전에 고칠 곳

`index.html`에서 `[직접 입력]`을 검색해 모두 바꿉니다.

- 연락 버튼 3개 (이메일, 인스타그램, 블로그): 버튼 글자와 `href`
- 서비스 상태와 출시 시기 문구

## GitHub Pages로 공개하기

1. 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소의 Settings → Pages로 이동합니다.
3. Source를 "Deploy from a branch"로 두고, Branch는 `main`, 폴더는 `/ (root)`로 선택한 뒤 저장합니다.
4. 1~2분 뒤 안내되는 주소(`https://아이디.github.io/저장소이름/`)로 접속합니다.

메뉴 이름은 GitHub 화면 개편으로 달라질 수 있습니다. (확인 필요)
